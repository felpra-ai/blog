# 범 얼굴 데칼 (req_catoffice_bengal_mvp 4-C 단계 대체)

범는 이 데칼을 쓰고, 4-C의 데칼 직접 제작은 건너뛴다.

## 파일
- 눈 (좌우 분리, 한쪽씩 깜빡일 수 있음): `face_eyes_{open|happy|half|focus}_{L|R}.png`
  - open = 기본 뜬 눈 (3D 텍스처와 색이 다를 때 덮어쓰는 용도)
  - happy = ^^ (범 기본 표정, 깜빡임의 '감은' 프레임으로도 사용)
  - half = 반쯤 감은 눈 (깜빡임 중간 프레임, '고민')
  - focus = 찡그린 눈썹 + 노려보는 눈 ('집중')
- 입: `face_mouth_{smile|flat|open|pout}.png`
- 모두 알파 PNG이고 가장자리는 부드럽게 페더 처리돼 있음. 원본 해상도의 2배로 업스케일함.

## 배치 (`decals_manifest.json`)
- 기준점: 코 윗부분(nose_top).
- 단위: 두 눈 중심 사이 거리 = 1.0.
- `center_offset` = 기준점에서 데칼 중심까지 [x(오른쪽+), y(아래+)], `size` = 데칼 폭·높이.
- 3D 머리에서 코 윗부분과 두 눈 중심 거리를 측정해 같은 비율로 평면을 배치하고, 머리 표면 법선 방향으로 0.5~1mm 띄운다.

## 조합 규칙
- 기본: 데칼 없음 (3D 텍스처의 뜬 눈 + 웃는 입), 범는 `happy` 눈을 기본으로 켠다.
- 깜빡임: open → half(40ms) → happy(60ms) → half(40ms) → open.
- 말하기: `mouth_open`을 6~8Hz로 켜고 끈다. 눈은 현재 표정 유지.
- 집중: `eyes_focus` + `mouth_pout`. 고민: `eyes_half` + `mouth_flat`.

## 한계
- 표정 시트의 얼굴 비율·조명은 3D 렌더와 다를 수 있다. 털 색이 튀면 데칼 텍스처의 색상만 3D 텍스처에 맞춰 보정한다(형태는 수정하지 않음).
- 눈 데칼 원본은 약 176×156px이다. 방송 화면 크기에서는 충분하지만, 얼굴 클로즈업 연출을 하려면 고해상도 표정 시트가 다시 필요하다.
